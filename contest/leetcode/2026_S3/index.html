    Q4 - Count Distinct Ways to Form Target from Two Strings

    練習用容斥計算方案數。

    • 限制: w1 及 w2 各至少選一個 定義 \(f(i, j, k)\) 為由 \(w_1[0: j]\) 和 \(w_2[0: k]\) 組成 target \(T[0: i]\) 的方案數，包含空串。

      設 \(g(s, t) 為\) s 在 t 中的方案數，透過減去 \(g(w_1, T)\) 和 \(g(w_2, target)\) 的方案數，可以得到至少選一個的方案數。

      \[f(w_1, w_2, tar) - g(w_1, tar) - g(w_2, tar)\]

      也就是 "選兩個構成 \(T\) 的方案數 - \(w_1\) 構成 \(T\) 的方案數 - \(w_2\) 構成 T 的方案數"

    • 解決 \(f(i, j, k)\):

    • 定義 \(f(i, j, k)\) 為由 \(w_1[0: j]\) 和 \(w_2[0: k]\) 組成 target \(T[0: i]\) 的方案數，包含空串。
    • 討論 \(w_1[j]\), \(w_2[k]\) 是否在 \(T\) 中，想像成是否出現在 \(T\) 的子集當中順序問題先不考慮:
      1. 都不在(都不選)
      2. 選 \(w_1[j]\) 在 \(T\) 中, 不在 \(w_2[k]\)
      3. 選 \(w_2[k]\) 在 \(T\) 中, 不在 \(w_1[j]\)
      4. \(w_1[j]\) 和 \(w_2[k]\)，都在 \(T\) 中 當兩個都在 \(T\) 時，由於 \(T[i]\) 一定屬於 \(w_1\) 或是 \(w_2\)，因此若是 \(w_1[j]\) 和 \(w_2[k]\) 都不匹配的話，表示 \(T[i]\) 會出現在 \(w_1[j]\) 跟 \(w_2[k]\) 更靠前的位置，使得無法滿足題目遞增的要求。 
        t  = aabbab  [b]
           /
w1 =   aasb  [d]
w2 =  abxsd  [a]
    • 如果 \(w_1[j]\) 不在 \(T\) 中，問題變成 \(T[0:i]\) 是由 \(w_1[0: j - 1]\) 和 \(w_2[0:k]\) 所組成的方案數為 \(f(i, j - 1, k)\) 包含情況 a, c
    • 如果 \(w_2[k]\) 不在 \(T\) 中，問題變成 \(T[0:i]\) 是由 \(w_1[0: j]\) 和 \(w_2[0:k - 1]\) 所組成的方案數為 \(f(i, j, k - 1)\) 包含情況 a, b
    • a = \(T[0:i]\) 是由 \(w_1[0: j - 1]\) 和 \(w_2[0:k - 1]\) 所組成的方案數 \(f(i, j - 1, k - 1)\)
    • 所以上面情況的方案數 \(a + b + c = f(i, j - 1, k) + f(i, j, k - 1) - f(i, j - 1, k - 1)\)

    • 情況 d : \(T[i]\) 一定要和 \(w_1[j]\) 和 \(w_2[k]\) 中一個匹配

      • \(T[i]\) 和 \(w_1[j]\) 匹配: 問題變成 \(T[0: i - 1]\) 是由 \(w_1[0: j - 1]\) 和 \(w_2[0: k]\) 組成，並且 \(w_2[k]\) 一定會出現在 \(T[0: i - 1]\) 中: 方案數 = \(f(i - 1, j - 1, k) -\) (不符合情況 d 的方案數) = \(f(i - 1, j - 1, k) -\) (不選 \(w_2[k]\) 的方案數) = \(f(i - 1, j - 1, k) -\) (在 \(w_1[0: j - 1]\) 和 \(w_2[0:k-1]\) 組成 \(T[0:i-1]\) 的方案數) = \(f(i - 1, j - 1, k) - f(i - 1, j - 1, k - 1)\)

    • 邊界定義:

      • \(f(j < -1) = f(k < -1) = 0\) ，-1 只是表示用完是合法的位置， \(< -1\) 是越界要回傳 0
      • \(f(j + 1 + k + 1 < i + 1) = 0\) : 剩下的 \(w_1, w_2\)無法構成 \(T\)
      • 最後若是 \(f(i < 0) = 1\)

    Biweekly Contest #187¶

    Q3 - Minimum Adjacent Swaps to Partition Array

    相鄰交換的最小次數的套路之前做過，結果沒發現，就是逆序對的個數，可以看做要穿越多少個元素才能抵達正確的區間。

    Q4 - Minimum Cost to Convert String III

    這題沒仔細讀題目，沒看到每次區間替換只能替換一次，所以以為是類似最短路之類的題目，隨便寫了一個最短路沒過就回去想 Q3，如果有發現每次區間只能替換一次的話那就是很簡單的區間 DP。

    Q3 - Transform Binary String Using Subsequence Sort

    這題中間有想到正確的思路，把 0/1分配成兩部分，結果我分配成 1 在左側， 0 在右側，結果卡在 s = 001，t=?0? 的測資。

    錯誤的點是，最後要操作的 s ，而 t 是操作後的結果，所以應該是要讓 t 越容易達成越好，因此 t 的 0 應該盡量在左側，1 儘量在右側。
