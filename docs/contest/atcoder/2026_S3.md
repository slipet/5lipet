F - Many Mod Calculation

沒做過數論相關的 DP。

首先觀察 $f(x) = (x \mod{a_0}) \mod{a_1}) ... ) \mod{a_n}$，可以發現對於 $a_i < a_j$ 會是沒有意義的，因為 $x \mod{a_i} = r \in [0, a_i]$，所以可以事先提取出新的 $a_i'$ 序列計算。因此我們會得到新的序列: $a_i' > a_{i+1}' > a_{i+2}' ... $。

觀察模運算$x \mod{a_i} = r \in [0, a_i]$，會把 x 切割成一個個完整的 $[0: a_i - 1]$ 區間，因為 0 不在我們的值域，可以把每個區間向左移一位 $[1:a_i - 1, 0]$。我們會得到 $\lfloor \frac{x}{a_i}\rfloor$ 個完整 $[1:a_i - 1, 0]$ 區間加上剩下的一個不完整區間 $[1: n]$

```
x % a_i = [1, ... , a_i - 1 , 0] ... [1, ... , a_i - 1 , 0] [1, 2, ... n]
```

可以注意到對於完整區間 $[1:a_i - 1, 0]$ 中的 0 因為已經整除所以可以提取出來，而剩下的 $[1, a_i - 1]$ 變成一個規模更小的子問題。可以寫出轉移方程: $$f(x, i) = \lfloor \frac{x}{a_i}\rfloor(f(a_i - 1, i + 1) + 1) + f(x \% a_i, j)$$

$f(x, i)$ 表示 $[1:x]$ 中模前 $a_i$ 為 0 的個數，其中 $+1$ 就是上面完整區間 $[1, ... , a_i - 1 , 0]$ 中 0 的部分。第二部分的 $f(x \% a_i, j)$ 為不完整區間的計算，因為進行模運算後可能 $a_{i + 1}$ 大於 $x \% a_i $，所以要透過二分方式找到第一個小於 $x \% a_i $ 的位置 $j$ 繼續計算。

可以看出來第一部份 $\lfloor \frac{x}{a_i}\rfloor(f(a_i - 1, i + 1) + 1)$ 的時間複雜度只跟模運算的次數有關 $O(N)$，第二部分則是要透過二分的方式找到 $j$ 所以要加上 $\log$ 為 $N\log{N}$

整體複雜度為 $O(N + N\log{N})$
